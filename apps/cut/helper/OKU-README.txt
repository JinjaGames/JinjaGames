JinjaCut Helper
===============
jinjagames.com/apps/cut sayfasi icin, kendi bilgisayarinda calisan ucretsiz indirme yardimcisi.
Free download helper for jinjagames.com/apps/cut that runs on your own computer.

TR
1. Windows: Baslat.bat dosyasini ac.  Mac / Linux: terminalde  sh baslat.sh
2. 1 = bu bilgisayar, 2 = telefon (QR kod cikar, telefonla okut).
3. Sayfa kendiliginden baglanmis olarak acilir. Pencereyi acik tut.
Python 3.8+ gerekir. yt-dlp, ffmpeg ve (telefon modu icin) cloudflared ilk calistirmada iner.
Dosyalar ve anahtar:  kullanici klasorun/.jinjacut

EN
1. Windows: open Baslat.bat.  Mac / Linux: run  sh baslat.sh  in a terminal.
2. 1 = this computer, 2 = phone (prints a QR code, scan it with the phone).
3. The page opens already connected. Keep the window open.
Needs Python 3.8+. yt-dlp, ffmpeg and (for phone mode) cloudflared are fetched on first start.
Files and key live in:  your home folder/.jinjacut

Yalnizca indirmeye hakkin olan icerikleri indir. / Only download what you are allowed to.
